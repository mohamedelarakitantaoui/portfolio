# SOPs (step-by-step for repeated jobs)

- [add-project.md](add-project.md): a new project in EN and FR, featured or "More projects".
- [add-case-study.md](add-case-study.md): chapters, model card, media for a project page.
- [edit-copy.md](edit-copy.md): change any text in EN and FR together.
- [add-media.md](add-media.md): encode videos and posters, size images, name files.
- [update-cv.md](update-cv.md): re-export the three CV PDFs and pass the CV check.
- [add-effect.md](add-effect.md): a new motion effect behind the kill switch.
- [release.md](release.md): deploy checklist, branch protection, CI.

Every SOP ends with `npm run check`. A task is not done until it passes.
