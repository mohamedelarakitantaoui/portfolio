<Chapter n="01" label="Problem" title="A shot's value depends on everyone else on the pitch.">

Expected goals (xG) is the probability that a shot becomes a goal. PitchPoint learns it from **99,000+ StatsBomb events** and looks at **where the players are** when the shot is taken, not only where the shooter stands.

</Chapter>

<Chapter n="02" label="Constraints" title="It has to work on matches it has never seen.">

- **Data:** 99,000+ StatsBomb events, with the positions of the players around each shot.
- **Generalisation:** a good cross-validation score is not enough; the model has to hold on out-of-distribution holdouts.
- **Proof first:** the evaluation harness had to exist before the first model was trained.

</Chapter>

<Chapter n="03" label="How it works" title="Two models, one prediction, one set of tests for everything.">

1. **an attention-based set encoder** reads the player positions as a set, so their order does not matter;
2. **LightGBM**, a gradient-boosted tree model, reads the shot's features;
3. the final xG is a **50/50 blend** of the two;
4. **an evaluation harness** checks every model the same way: grouped cross-validation, calibration, out-of-distribution holdouts and clustered bootstrap significance tests, with **444 tests** passing.

</Chapter>

<Chapter n="04" label="Key decisions and trade-offs" title="I built the tests before the model.">

- **The evaluation harness before any model.** I built the harness first, so the set encoder and its baselines, gradient boosting and a linear model, were all judged by the same tests.
- **A set encoder over fixed-order features.** The players around a shot have no natural order, so I chose a model that reads them the same way whatever order they arrive in.
- **A 50/50 blend over either model alone.** The blend scored better than both models, in cross-validation and on out-of-distribution holdouts, so I kept both instead of picking one.

</Chapter>

<Chapter n="06" label="Limitations and what I'd do next" title="My hypothesis was wrong, and the tests said so.">

I expected the attention encoder to pay more attention to players **outside the shooting cone**. Occlusion tests, which hide players one at a time and measure the change, said it doesn't. I kept the result and dropped the story.
