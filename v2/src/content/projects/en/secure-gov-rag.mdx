<Chapter n="01" label="Problem" title="The documents can't leave the building, so neither can the model.">

A public body needs answers from its own files without sending those files to a cloud API. Everything has to run on its own servers: the language model, the search index and the document storage. Users read and write in Arabic, French and English.

<Chapter n="02" label="Approach" title="Local models, cited answers, and a log of who asked what.">

- **Local inference.** Models are served by Ollama on the same network; no request goes out.
- **Answers restricted to retrieved context**, with links back to the source passages, to reduce hallucination.
- **Guardrails** against prompt injection.
- **Role-based document access** through Keycloak, so a user only retrieves what they may read.
- **A full audit log** of questions, sources and answers.
- **A second pipeline** turns PDF tables into Excel, with drag-and-drop upload and status tracking.

</Chapter>
