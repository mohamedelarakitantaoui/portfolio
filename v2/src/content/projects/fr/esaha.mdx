Chaque page est derrière l’authentification et des routes protégées. Les sept modules :

- authentification sécurisée ;
- annuaire de spécialistes ;
- chat en temps réel avec les praticiens ;
- journal privé pour suivre ses progrès ;
- prise de rendez-vous avec calendrier ;
- contacts d’urgence ;
- bibliothèque de ressources, plus les réglages utilisateur.
